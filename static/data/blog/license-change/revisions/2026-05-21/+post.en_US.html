License Change

There have been some changes made that I should let everyone know about.

On the GitHub repository for this website, in pull request #1 the LICENSE file has changed.
It used to contain the Creative Commons Zero v1.0 Universal license (CC0-1.0), but that has changed to the Apache License 2.0 (Apache-2.0)

To explain what this means, CC0-1.0 effectively places a work into the public domain with no copyright or conditions, while Apache-2.0 allows broad use and modification but still requires notices, providing the license, and grants explicit patent rights.

I have proposed this change, and after discussion, Varrow and I agreed to relicense the website code under the Apache-2.0 license.

This was done because we want to use a professional software license that respects the project and provides our code with clearer legal guarantees. For us, infrastructure and expression serve different purposes, so we're going to license them differently.

Meaning, all the content on the website, any blog posts like this one, future articles, creative projects, public messages or information will stay as CC0. So unless stated otherwise, all non-code content published by ELECTRIS will remain under CC0.

In my mind, whatever I create should belong to everyone. I want to spread creation far and wide, for anyone anywhere, and so, I waive as many rights to my creations as legally possible. I do not care whether people remember my name. I care whether they remember what was created, why it matters, and what ELECTRIS stands for. Names fade. Creativity does not.

That leads me to my last point. The likeness of the project, the ELECTRIS name, branding, and visual identity remain reserved and protected to prevent impersonation or misrepresentation of our project. We want to spearhead this movement, and are willing to accept any of the risks that come with it.
